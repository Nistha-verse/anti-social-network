# The Anti-Social Network

The Anti-Social Network is a characterful, permissionless Solana devnet demo for making tiny judgments official. A wallet can create one profile, leave a fixed-price **Downvote** or **Boo** receipt for any other public key, and retract its own receipt without deleting the public record or receiving a refund.

This repository contains the Anchor program, its integration tests, a real-wallet React frontend, and the measurement helper used for this deployment.

## Data authenticity

Every judgment shown by the app is a real devnet account read from Solana RPC. There is no mock, simulated, seeded, fixture, database, backend, indexer, or hardcoded wallet/judgment data in the app. The demo is performed live with wallets the owner controls. Characters are deterministic presentation derived from the wallet public key; no avatar data is stored on-chain. Devnet SOL has no market value, so the economics are symbolic on devnet; the same fixed-price program could be deployed to mainnet only as a deliberate future decision.

The app has honest loading, empty, and RPC-error states. `getProgramAccounts` is rate-limited on public RPC, so use a dedicated devnet endpoint for a live demo when possible. The default remains the public Solana devnet endpoint so the project can be tried without a provider account.

## Architecture

```text
real wallet (Wallet Standard)
          │ signs
          ▼
React + Vite app ── Anchor client ── devnet RPC
          │                              │
          │ reads PDA accounts/events    │ owns and serves
          ▼                              ▼
  profile / judgment / pool PDAs ◄── anti_social_network program
          │
          └── Explorer links + raw-byte verification
```

There is no initialization instruction. The Spite Pool is the `SystemAccount` PDA `PDA(["spite_pool"])`; it is never initialized by this program and can only receive lamports through the atomic judgment instruction.

## Program accounts

All sizes include the 8-byte Anchor discriminator.

| Account | Seeds | Fields / raw layout | Size |
| --- | --- | --- | ---: |
| Profile | `profile`, owner | owner `Pubkey`; username `String` max 32 bytes; metadata URI `String` max 100 bytes; judgment_count `u64`; created_at `i64`; updated_at `i64`; bump `u8` | 205 |
| Judgment | `judgment`, actor, id as little-endian `u64` | discriminator 0; id `u64` 8; actor `Pubkey` 16; target `Pubkey` 48; kind `u8` 80; amount `u64` 81; status `u8` 89; created_at `i64` 90; retracted_at `Option<i64>` 98; bump `u8` 107 | 108 |
| Spite Pool | `spite_pool` | data-less System Program account; no fields | 0 data bytes |

Judgment enum discriminants are fixed by declaration order: `Downvote = 0`, `Boo = 1`; status is `Active = 0`, `Retracted = 1`.

## Instructions

| Instruction | What it does | Fixed price |
| --- | --- | ---: |
| `create_profile(username, metadata_uri)` | Creates `Profile(["profile", owner])`, validates UTF-8 byte lengths, and emits `ProfileCreated` | account rent |
| `update_profile(username, metadata_uri)` | Replaces both strings and updates `updated_at` | network fee |
| `downvote(target)` | Creates the next actor receipt, increments the actor counter, and transfers the fixed price atomically | 1,000,000 lamports |
| `boo(target)` | Same shared judgment flow with the Boo kind | 10,000,000 lamports |
| `retract_judgment()` | Marks the actor's active receipt Retracted; it does not refund, close, or move pool lamports | network fee |

The program rejects empty or overlong usernames, overlong URIs, self-judgment, missing profiles, invalid/stale PDAs, unauthorized or duplicate retractions, overflow, fake pool addresses, and underfunded atomic transactions.

## Toolchain and setup in WSL

The checked-in runtime pins Rust `1.98.1`; `Cargo.lock` and `app/package-lock.json` are committed. The implementation was built with:

```text
anchor-cli 1.2.0
solana-cli 3.1.10
rustc 1.98.1
node v24.10.0
```

Install the Linux toolchain inside WSL2 Ubuntu, then from the repository root:

```bash
npm install
anchor build
npm test
cd app
npm install
cp .env.example .env.local
npm run build
npm run dev -- --host 0.0.0.0
```

Open the Vite URL forwarded by WSL in a Windows browser. `VITE_RPC_URL` defaults to `https://api.devnet.solana.com`; set it in `app/.env.local` to a dedicated devnet RPC for a demo. `VITE_PROGRAM_ID` defaults to the deployed program below. All `VITE_*` values are public bundle configuration and must not contain secrets.

Install a real Phantom, Solflare, Backpack, or other Wallet Standard wallet in the Windows browser, switch it to **Devnet**, and get test SOL from the [official Solana faucet](https://faucet.solana.com/). The app never sees a private key and never generates an in-browser keypair.

## Tests

`npm test` ran the full Anchor suite against the installed Anchor 1.2.0 default local Surfpool validator: **14 passing**. `anchor build` passed. The suite covers the full happy-path, failure-path, rollback, first-deposit, size, and raw-offset matrix in `tests/anti-social.ts`.

The legacy validator path was also attempted, but the installed Solana 3.1.10 validator rejected the generated eBPF ELF with `invalid file header` during program deployment. That environment limitation is recorded in `DECISIONS.md`; `npm test` uses the working default local validator and remains the single test command.

## Security properties

- Every write requires a real signer; `actor` is not spoofable.
- Profile and Judgment PDAs enforce ownership, actor, and sequential little-endian IDs.
- `target` is an instruction argument only, so any public key can be judged without needing a target account or profile.
- Program prices are constants selected on-chain; clients cannot set the amount.
- Profile input validation is byte-based and account sizes are bounded with `InitSpace`.
- Payment, account creation, receipt population, and counter increment are atomic in one instruction.
- Retraction checks `has_one = actor`, only accepts Active receipts, and never moves lamports.
- The frontend checks `getGenesisHash` against the published devnet hash `EtWTRABZaYq6iMfeYKouRu166VU2xqa1wcaWoxPkrZBG` before enabling writes. The check follows Solana's [`getGenesisHash` RPC documentation](https://solana.com/docs/rpc/http/getgenesishash).
- Usernames and metadata are rendered as text. A metadata URI becomes a link only for `http://` or `https://`, with `noopener noreferrer`; remote images are never auto-loaded.

## Honest known limits

- A price is a commitment, not spam prevention, especially on devnet.
- Judgment and profile rent are non-refundable. A receipt is public and permanent, even after retraction.
- Usernames are not unique, so the UI always keeps the wallet address visible.
- Public RPC and `getProgramAccounts` do not scale to a production social network. A production version needs an indexer and dedicated RPC infrastructure; this demo intentionally has neither.
- Devnet can reset, public endpoints rate-limit, and devnet SOL has no market value.
- The pool has no withdrawal instruction. Its exact RPC balance is shown beside a decorative, bounded jar.
- The live static app is hosted at [app-nu-rose-23.vercel.app](https://app-nu-rose-23.vercel.app/). It is a Vercel production deployment of `app/` with an SPA rewrite for `/w/<pubkey>`, `/me`, and `/pool`.

## Seven-step demo script

1. Open the live Vite app, confirm the **DEVNET** badge, connect a real wallet, and create a profile. The profile form shows the measured rent cost before the wallet prompt.
2. Paste a real target wallet into Discover. The target gets a deterministic character even if it has no Profile account.
3. Read the target's receipts, expand **Verify it yourself**, and compare actor, target, kind, amount, and status against raw account bytes.
4. Press **Boo**. Review the real price, one-time Judgment rent from `getMinimumBalanceForRentExemption(108)`, and 5,000-lamport base fee before opening the wallet approval prompt.
5. After signing, show the new receipt, its Explorer account link, the toast transaction link, and the exact Spite Pool total rising.
6. Open **My profile** and show the client-computed downvote, Boo, retraction, and retraction-rate stats.
7. Retract an active receipt. Show the RETRACTED stamp, retraction time, unchanged pool, and the original creating transaction/account still visible on Explorer.

## Reproducibility files

The public repository is [github.com/Nistha-verse/anti-social-network](https://github.com/Nistha-verse/anti-social-network). It keeps all dependencies inside the project, commits lockfiles, ignores `.keys/`, `target/`, `node_modules/`, and `.env*`, and never includes keypairs or secrets. `docker build -t anti-social-network:local .` builds the frontend from the locked `app/package-lock.json` and the image serves it on port 4173.
